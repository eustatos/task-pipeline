# Implement event stream replay for recovery

## Objective
Implement replay of the event stream to rebuild the derived state after a crash,
applying events in sequence order up to an optional target sequence number.

### Not Included
- The stream implementation itself (T1.3.2)
- Checkpoint-based recovery (Stage 2)
- Parallel or partial replay

## Context
Replay is the recovery primitive used by the upper loop after an interrupt or
crash. It relies on the append-only guarantee from C0.5 and the typed events
from T1.3.1.

## Tech Stack & Constraints
- Python 3.11
- `EventStream` from T1.3.2, `BaseState` from T1.2.1, typed `Event.payload` from T1.3.1
- Reducers are pure functions: `(state, event) -> state`, dispatching on `event.type`
- Reducers stay type-safe because `event.payload` is a typed model

## Input/Output Contracts

```python
Reducer = Callable[[BaseState, Event], BaseState]

def replay(
    events: Iterable[Event],
    initial: BaseState,
    reducer: Reducer,
    until: int | None = None,
) -> BaseState: ...
```

- Events are applied strictly in ascending `sequence_number`
- A duplicate or out-of-order sequence raises `ReplayError`

## Acceptance Criteria

| ID | Input | Expected Behavior | Verification |
|----|-------|-------------------|--------------|
| AC1 | Ordered events | Final state equals the incremental application | `pytest -k replay_full` |
| AC2 | `until=N` | Replays exactly through sequence N | `pytest -k replay_until` |
| AC3 | Out-of-order events | `ReplayError` raised | `pytest -k replay_out_of_order` |
| AC4 | Empty stream | Returns the initial state unchanged | `pytest -k replay_empty` |
| AC5 | `tool_call` event | Reducer receives a `ToolCallPayload` (not a dict) | `pytest -k replay_typed` |

## Boundaries

| Tier | Rules |
|------|-------|
| Always | Apply events in strict sequence order; keep reducers pure; dispatch on `event.type` |
| Ask First | Changing the reducer signature; adding side effects to reducers |
| Never | Reorder events; mutate the seed state in place; treat `payload` as an untyped dict |
