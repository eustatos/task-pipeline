# Concurrent register/unregister test (zero race conditions)

## Objective
Write a deterministic concurrency test that hammers `register()` and
`unregister()` from multiple threads and asserts the registry never enters a
partial or corrupted state.

### Not Included
- Fixing the registry implementation (T1.1.2), unless the test exposes a defect
- Load/stress testing beyond registry mutation
- Role-based access tests (T1.1.5)

## Context
DoD criterion C0.2 requires zero race conditions and zero partial state. This
test is the evidence artifact for that criterion and gates merges to main.

## Tech Stack & Constraints
- Python 3.11
- `pytest` + `concurrent.futures.ThreadPoolExecutor`
- Deterministic: no `time.sleep` used as synchronization

## Input/Output Contracts

```python
def test_concurrent_register_unregister() -> None:
    # N threads register/unregister M tools each
    # after join: registry state matches the expected final set
    ...
```

## Acceptance Criteria

| ID | Input | Expected Behavior | Verification |
|----|-------|-------------------|--------------|
| AC1 | 100 concurrent mixed ops | No unexpected exception escapes | `pytest -k concurrent_no_crash` |
| AC2 | 100 concurrent mixed ops | Final state equals the computed expected set | `pytest -k concurrent_final_state` |
| AC3 | Repeat 100 iterations | No flaky failure across runs | `pytest -k concurrent -x --count=100` |
| AC4 | Race window probe | No observable partial state at any observation point | `pytest -k no_partial_state` |

## Boundaries

| Tier | Rules |
|------|-------|
| Always | Make the test deterministic; assert on final invariants |
| Ask First | Introducing a concurrency dependency (e.g. pytest-xdist) |
| Never | Synchronize with `time.sleep`; mark the test flaky; skip on failure |
