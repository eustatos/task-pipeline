# Define ToolSpec Pydantic model

## Objective
Define the `ToolSpec` Pydantic model that describes a registered tool's contract:
name, input schema, output schema, timeout, and allowed roles. This model is the
structural contract enforced by the Tool Registry (ADR-006).

### Not Included
- `ToolRegistry` implementation (T1.1.2)
- Role filtering logic (T1.1.3)
- Concrete tool implementations (Stage 3)

## Context
Every tool in the core must declare a typed contract before it can be registered.
`ToolSpec` is the single source of truth for tool metadata and is validated at
registration time. See `docs/adr/ADR-006-tool-registry.md`.

## Tech Stack & Constraints
- Python 3.11, Pydantic v2.x (see `backlog/_conventions.md`)
- Do NOT add runtime dependencies beyond pydantic

## Input/Output Contracts

```python
class AgentRole(str, Enum):
    """Agent role this task is primarily assigned to."""
    PLANNER = "planner"
    EXECUTOR = "executor"
    REVIEWER = "reviewer"


class ToolSpec(BaseModel):
    name: str                       # unique, snake_case
    input_schema: type[BaseModel]   # Pydantic model class
    output_schema: type[BaseModel]  # Pydantic model class
    timeout: float                  # seconds, > 0
    roles: list[AgentRole]          # non-empty, unique
```

> `AgentRole` is defined here because the registry is its first consumer
> (T1.1.3). It is part of the Stage 1 contract surface.
