# State serialization with corruption detection (checksum)

## Objective
Implement state serialization to disk and deserialization back, with a checksum
that detects truncated or tampered content. Corrupted payloads must be reported
with a meaningful error, never silently loaded.

### Not Included
- Migration logic (T1.2.2)
- Concurrency control for state writes (Stage 5)
- Encryption or signing of the payload

## Context
DoD criteria C0.4 and C4.4 require corruption detection. The checksum is the
first line of defense for persisted state; recovery policy lives in Stage 5.

## Tech Stack & Constraints
- Python 3.11
- Pydantic v2.x, `BaseState` from T1.2.1
- Checksum: SHA-256 over the canonical JSON payload
- Canonical JSON: sorted keys, UTF-8, no insignificant whitespace
- The store tracks `updated_at` on write (see T1.2.1)

## Input/Output Contracts

```python
class StateStore:
    def save(self, state: BaseState, path: Path) -> None: ...
    def load(self, path: Path) -> BaseState: ...
```

- The on-disk envelope is `{"checksum": "<sha256>", "payload": <canonical json>}`
- `load` raises `StateCorruptionError` when the checksum does not match
- The **canonical envelope bytes** are the guarantee, not the original model's
  field order — two equal states always serialize to identical envelope bytes

## Acceptance Criteria

| ID | Input | Expected Behavior | Verification |
|----|-------|-------------------|--------------|
| AC1 | Save then load | Round-trips to an equal state | `pytest -k roundtrip` |
| AC2 | Same state, different field insertion order | Identical checksum (canonical) | `pytest -k canonical` |
| AC3 | Payload byte flipped | `StateCorruptionError` raised | `pytest -k corruption_detected` |
| AC4 | Truncated file | `StateCorruptionError` raised | `pytest -k truncated` |
| AC5 | Save | Envelope on disk has `updated_at` set | `pytest -k updated_at` |

## Boundaries

| Tier | Rules |
|------|-------|
| Always | Verify the checksum before parsing; use canonical JSON for the hash |
| Ask First | Changing the envelope format; changing the hash algorithm |
| Never | Load unverified payloads; catch `StateCorruptionError` and continue silently |
