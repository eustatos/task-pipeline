# Define CoreConfig as a Pydantic Settings model

## Objective
Define `CoreConfig` as a Pydantic Settings model sourced exclusively from
environment variables. Every setting is a typed field with an explicit default or
a required marker.

### Not Included
- Fail-fast startup wiring (T1.4.2)
- The validation test matrix (T1.4.3)
- Secrets management integration

## Context
DoD criterion C0.6 requires validated configuration at startup (ADR-005).
Configuration is consumed as environment variables only — administrators have no
code access and manage settings through environment, not YAML property files.

## Tech Stack & Constraints
- Python 3.11, `pydantic-settings` v2.x (see `backlog/_conventions.md`)
- Env prefix: `PIPELINE_` (e.g. `PIPELINE_MODEL_NAME`)
- No settings loaded from YAML or INI files

## Input/Output Contracts

```python
class CoreConfig(BaseSettings):
    model_name: str = "qwen3-coder"
    max_retries: int = Field(3, ge=0, le=10)
    log_level: Literal["DEBUG", "INFO", "WARNING", "ERROR"] = "INFO"
    state_dir: Path          # required, no default
    api_base_url: AnyHttpUrl  # required, no default

    model_config = SettingsConfigDict(env_prefix="PIPELINE_")
```

> Required fields (`state_dir`, `api_base_url`) have no default and MUST be
> provided as env vars. All other fields have documented defaults.

## Acceptance Criteria

| ID | Input | Expected Behavior | Verification |
|----|-------|-------------------|--------------|
| AC1 | All required env vars set | `CoreConfig()` validates | `pytest -k config_valid` |
| AC2 | Missing `PIPELINE_STATE_DIR` | ValidationError raised (required field) | `pytest -k config_required` |
| AC3 | `PIPELINE_MAX_RETRIES=99` | ValidationError raised (bound) | `pytest -k config_bounds` |
| AC4 | Optional fields absent | Documented defaults applied | `pytest -k config_defaults` |
| AC5 | Source scan | No YAML/INI settings loader present | `pytest -k config_env_only` |

## Boundaries

| Tier | Rules |
|------|-------|
| Always | Read settings from env vars only; type every field; validate bounds |
| Ask First | Adding a required field; changing the `PIPELINE_` prefix |
| Never | Ship a default for a secret; read settings from YAML; use untyped `dict` config |
