# Implement ToolRegistry with atomic register/unregister

## Objective
Implement an in-memory `ToolRegistry` supporting atomic `register()` and
`unregister()`. On any failure the registry state must remain unchanged (no
partial inserts or removals).

### Not Included
- Role-based access filtering (T1.1.3)
- Persistence to disk or database
- Concrete tool implementations (Stage 3)

## Context
The registry is the single point of truth for tool lifecycle (ADR-006) and is
subject to DoD criterion C0.2: atomic registration with zero partial state.
The registry is populated from config at startup and read concurrently at runtime.

## Tech Stack & Constraints
- Python 3.11, Pydantic v2.x (`ToolSpec` from T1.1.1)
- `threading.Lock` or an equivalent primitive for mutation safety

## Input/Output Contracts

```python
class ToolRegistry:
    def register(self, spec: ToolSpec) -> None: ...
    def unregister(self, name: str) -> None: ...
    def get(self, name: str) -> ToolSpec: ...
```

- `register` on a duplicate name raises `RegistryError` and leaves state unchanged
- `unregister` on an unknown name raises `RegistryError` and leaves state unchanged
- `get` on an unknown name raises `RegistryError`

## Acceptance Criteria

| ID | Input | Expected Behavior | Verification |
|----|-------|-------------------|--------------|
| AC1 | Valid ToolSpec | Tool is retrievable via `get` | `pytest -k register_adds` |
| AC2 | Duplicate name | `RegistryError`; prior spec unchanged | `pytest -k duplicate` |
| AC3 | Unregister existing | Tool no longer retrievable | `pytest -k unregister` |
| AC4 | Unregister unknown | `RegistryError`; state unchanged | `pytest -k unregister_missing` |
| AC5 | Mutation guard | Concurrent mutation test (T1.1.4) shows no partial state | `pytest -k atomic` |

## Boundaries

| Tier | Rules |
|------|-------|
| Always | Guard every mutation with a lock; validate the spec before insert |
| Ask First | Changing the mutation primitive; adding bulk operations |
| Never | Expose the internal mapping; allow partial state on error; swallow exceptions |
