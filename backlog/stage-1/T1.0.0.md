# Project scaffolding and conventions

## Objective
Create the package layout, dependency pinning, test layout, and shared test
fixtures that every other Stage 1 task builds on. This is the first task to write
code; it absorbs the cross-cutting concerns that would otherwise be reinvented per
task.

### Not Included
- Any feature logic (that is the job of T1.1.x–T1.5.x)
- CI wiring (T1.5.1) or the mypy gate (T1.5.2)
- Documentation of architecture (Stage 6)

## Context
The Stage 1 tasks reference a `src/core/` package, a `tests/core/` tree, and a set
of pinned dependencies (pydantic, pydantic-settings, pytest, hypothesis,
jsonschema, mypy) without any of them existing yet. This task makes those
assumptions real and defines the one place shared rules live
(`backlog/_conventions.md`).

## Tech Stack & Constraints
- Python 3.11
- Toolchain pinned in `pyproject.toml` / `requirements-dev.txt`
- Must match `backlog/_conventions.md`

## Input/Output Contracts

```
src/
├── __init__.py
└── core/
    ├── __init__.py
    └── (feature modules land here in T1.1.x–T1.4.x)
tests/
├── __init__.py
├── core/
│   ├── __init__.py
│   └── conftest.py        # shared fixtures (tmp state dir, sample tools, env monkeypatch)
└── fixtures/
    └── state/v1/          # v1 state fixtures for T1.2.3
```

- `conftest.py` exposes fixtures: `tmp_state_dir`, `sample_tool_specs`, `clean_env`
- A `make stage1` / `just stage1` target runs `pytest tests/ && mypy --strict src/`

## Acceptance Criteria

| ID | Input | Expected Behavior | Verification |
|----|-------|-------------------|--------------|
| AC1 | Import `src.core` | Package resolves with no error | `python -c "import src.core"` |
| AC2 | `pytest tests/ --collect-only` | Collects with zero errors | `pytest tests/ --collect-only` |
| AC3 | Shared fixtures present | `tmp_state_dir`, `sample_tool_specs`, `clean_env` available | `pytest tests/ -k fixture_smoke` |
| AC4 | Deps pinned | `requirements-dev.txt` / `pyproject.toml` pins all toolchain deps | `pip check` + diff |
| AC5 | `make stage1` (or `just stage1`) | Runs suite + mypy in one command | `make stage1` |

## Boundaries

| Tier | Rules |
|------|-------|
| Always | Keep this task free of feature logic; pin every toolchain dep |
| Ask First | Choosing the runner (make vs just) or the test layout |
| Never | Add feature code here; leave toolchain deps unpinned; duplicate convention text in task files |
