# Property test: event immutability (10K events, zero violations)

## Objective
Write a property-based test that appends up to 10K events and asserts that no
previously appended event is ever mutated or lost.

### Not Included
- The stream implementation (T1.3.2)
- Replay logic (T1.3.4)
- Concurrency (this test is single-threaded; see T1.3.2 scope note)

## Context
DoD criterion C0.5 requires zero immutability violations across 10K events. This
test is the evidence artifact and runs in the Stage 1 merge gate (T1.5.1).

## Tech Stack & Constraints
- Python 3.11
- `pytest` + `hypothesis`
- Deterministic given a seed; failures print the seed
- Runs **single-threaded** (tests append-only immutability, not concurrency)


| ID | Input | Expected Behavior | Verification |
|----|-------|-------------------|--------------|
